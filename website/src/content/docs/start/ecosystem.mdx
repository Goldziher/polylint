polylint is part of the [polylint organization](https://github.com/polylint): high-performance Rust
linters and formatters built for agentic workflows. Each tool is a standalone CLI with its own
releases, and poly embeds the siblings as opt-in engines so one `poly.toml` can drive them.

## Inside poly

| Tool | poly engine | Enable with |
| --- | --- | --- |
| skif | `skif`, a project check in the `web` component | `[engines.skif] enabled = true` |
| adrlint | `adrlint`, in the `web` component; `poly adr` maintains the log | `[engines.adrlint] enabled = true` |
| uncomment | `uncomment`, the `uncomment` component | `[engines.uncomment] enabled = true` |

See [Languages and engines](/polylint/reference/backends/) for what each engine covers. skif has its own
documentation site at [polylint.github.io/skif](https://polylint.github.io/skif/).

## Installing the standalone tools

Every tool in the organization ships from the same Homebrew tap and Scoop bucket:

```sh
brew tap polylint/tap
brew install polylint/tap/<tool>
```

```powershell
scoop bucket add polylint https://github.com/polylint/scoop-bucket
scoop install <tool>
```

The npm packages live under the `@polylint` scope. Each tool's README lists its other channels.
